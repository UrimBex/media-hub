Auto-organiser

A free Python script that sorts movies, TV, music and videos into a clean library, finds duplicates and downloads posters and album covers.

Run it

Install Python 3 from python.org (on Windows, tick “Add python.exe to PATH”). Download the repository, open a terminal in tools/mediaorg, copy config.example.json to config.json and set your inbox and library folders. On Windows type python instead of python3.

1. See the plan, changes nothing
python3 mediaorg.py
2. Do it
python3 mediaorg.py --apply
Posters, plots and album covers (TMDb key in config; MusicBrainz needs none)
python3 mediaorg.py --apply --metadata
Duplicate report for the whole library
python3 mediaorg.py --dupes
Keep sorting new downloads every 15 minutes
python3 mediaorg.py --watch 15 --metadata
Optional: read music tags
pip install mutagen
