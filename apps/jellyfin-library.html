01

Name your files the way Jellyfin reads them

Jellyfin finds cover art, synopses, cast and genres by matching folder and file names against TheMovieDb. Good names are 90% of a clean library. Keep three separate top-level folders, one per library.

Media/
├── Movies/
│   ├── Spirited Away (2001)/
│   │   ├── Spirited Away (2001).mkv
│   │   ├── Spirited Away (2001).en.srt          # subtitles, language code before .srt
│   │   └── trailers/                             # extras live in named subfolders
│   └── The Matrix (1999) [tmdbid-603]/         # optional id = guaranteed match
│       ├── The Matrix (1999) - 1080p.mkv         # two versions of one film
│       └── The Matrix (1999) - 2160p.mkv
├── Shows/
│   └── Bluey (2018)/
│       ├── Season 00/                            # specials
│       ├── Season 01/
│       │   ├── Bluey (2018) S01E01.mkv
│       │   └── Bluey (2018) S01E02.mkv
│       └── Season 02/
└── Home Videos/
    └── 2023/
        ├── 2023-07-14 Beach day.mp4
        └── 2023-12-25 Christmas morning.mov

02
Install the Jellyfin server

      
Pick one route. Both end with Jellyfin open in your browser at http://localhost:8096, where a short wizard creates your admin account.

      

        
        
      

      

        
Windows
Download the installer from jellyfin.org/downloads. Choose "Install as a service" so it starts with the laptop, even before you log in.

        
macOS
Download the .dmg, drag Jellyfin to Applications, open it. Add it to System Settings → General → Login Items so it starts automatically.

        
Linux (Ubuntu / Debian)

          
terminal
curl https://repo.jellyfin.org/install-debuntu.sh | sudo bash

04
Categories, collections and search

      
Most organisation happens automatically once metadata is in. These tools let you shape it the way your household browses.

      

        
Genres
Filled in from TheMovieDb. Each library has a Genres tab, so "Animation" or "Documentary" is one click away.

        
Collections
Select titles → ⋯ → Add to collection. Make your own shelves like "Friday Family Night", "Studio Ghibli" or "Christmas".

        
Tags
Open a title → ⋯ → Edit metadata → Tags. Tags power parental filters and custom categories that cut across libraries.

        
Search
The magnifier searches titles, actors, directors and genres across every library. It works the same in the apps.

        
Home screen
Each user picks their own home rows in Settings → Home: Continue Watching, Next Up, Latest Movies and so on.

        
Profiles
Dashboard → Users: one account per person keeps watch progress separate. Set a maximum parental rating and choose which libraries each user sees.

05
Stream to other devices on your Wi‑Fi

      
Every device on the same network can reach the laptop at http://LAPTOP-IP:8096. Find the address, let it through the firewall, and keep it from changing.

      

        
        
        
      

      

        PowerShell
        
        

      

      

        
Keep the address fixed
In your router's admin page, find the laptop under connected devices and choose "DHCP reservation" or "Static lease". Then bookmarks and TV apps keep working.

        
Smooth playback
Dashboard → Playback → Transcoding: turn on hardware acceleration for your GPU (Intel QSV, NVIDIA NVENC, AMD/Intel VA-API, or Apple VideoToolbox). Use a cable for the laptop if Wi‑Fi stutters on 4K.

        
Let TVs find it
Dashboard → Networking: leave "Enable auto discovery" on (UDP 7359). Most Jellyfin TV apps then list the server without typing an address.

    •

Home network only. This setup keeps Jellyfin inside your house. Don't forward port 8096 on your router. If you later want access away from home, use a private VPN such as Tailscale or WireGuard instead of exposing the server to the internet.
