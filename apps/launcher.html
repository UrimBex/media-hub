Your own library

Self-hosted, open-source servers for the files you already own.

Running on this laptop

Once the stack below is up, these open your servers. Change the host to reach them from a TV or phone on the same Wi‑Fi.

Set it up in about 15 minutes

  1. Install Docker Desktop (free for personal use).
  2. Make a folder ~/Media with Movies, TV, Music, Podcasts inside.
  3. Save the file below as docker-compose.yml in a new folder and run docker compose up -d.
  4. Open Jellyfin, create your admin user, then add libraries pointing at /media/Movies, /media/TV and so on.
services:
  jellyfin:            # movies, TV, docs, home videos
    image: jellyfin/jellyfin:latest
    ports: ["8096:8096"]
    volumes:
      - ./jellyfin/config:/config
      - ./jellyfin/cache:/cache
      - ~/Media:/media:ro
    restart: unless-stopped

  navidrome:           # music streaming (Subsonic API)
    image: deluan/navidrome:latest
    ports: ["4533:4533"]
    volumes:
      - ./navidrome:/data
      - ~/Media/Music:/music:ro
    restart: unless-stopped

  audiobookshelf:      # podcasts + audiobooks, auto-downloads
    image: ghcr.io/advplyr/audiobookshelf:latest
    ports: ["13378:80"]
    volumes:
      - ./abs/config:/config
      - ./abs/metadata:/metadata
      - ~/Media/Podcasts:/podcasts
    restart: unless-stopped
  1. Install the Jellyfin server for Windows, macOS or Linux. It opens at port 8096.
  2. Install Navidrome as a single binary, or skip it and use Jellyfin's music library.
  3. For podcasts, use gPodder on desktop or AntennaPod on Android. No server needed.
  4. For a full-screen TV feel, install Kodi and add the Jellyfin add-on, or use Jellyfin Media Player.
  5. Install VLC as the fallback player for any file format.

Your files

Jellyfin fetches posters, plots and subtitles, remembers where you stopped, and streams to any device on your network. Rip discs you own or keep downloads you bought.

Free streaming

Ad-supported services and library-card services carry thousands of licensed films and shows. Availability depends on your country.

Open feeds

Podcasts are plain RSS, so any open-source app can subscribe. PeerTube and the Internet Archive host video under open licences.
